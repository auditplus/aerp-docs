This is the most required master to begin anything related to branch, accounts, sales, etc.

## New Gst Registration

![Gst Registration Form](./1-new-gst-registration.png)

Required Field are,
  * Gst Registration Type - Now, we support only `REGULAR`.
  * GSTIN - A valid GST Number
  * Location  - Select based on the first 2 digits of gst number. Ex: 33-Tamilnadu
  * Legal Name - The party who holds this gst number

:::note
For demo purpose:
**[Get Demo GST Number](https://stackblitz.com/edit/typescript-svsrga?file=index.ts)** 
:::  

Optional Fields are
  * Trade Name - Shop name, how party knowns

Gst Filling
  * Username - username given by gst portal to file GSTR1

E-Invoice Portal - it can be generated yourself from e-invoice portal
  * Username - username to login e-invoice portal  
  * Password - password to login e-invoice portal  

:::note
You can get EInvoice Portal credentials, by registering from **[E-Invoice Portal](https://einvoice1.gst.gov.in)**
:::
