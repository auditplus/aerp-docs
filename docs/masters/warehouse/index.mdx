## New Warehouse

Menu -> `Warehouse`

![New Warehouse](./new-warehouse.png)   

Required Fields
  * Name - Warehouse name

Optional Fields
  * Email
  * Mobile
  * Telephone
  * Address
  * City
  * Pincode
  * State - [State Search box](../../know-before-enter#state-search-box)
  * Country - [Country Search box](../../know-before-enter#country-search-box)
